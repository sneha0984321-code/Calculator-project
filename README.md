# 🧮 Calculator

A simple and user-friendly calculator project designed to perform basic arithmetic operations. This project demonstrates fundamental programming concepts and provides a practical implementation of mathematical calculations.

## 📌 About the Project

This Calculator is a beginner-friendly project developed to perform everyday mathematical operations through a simple interface.

It is built to practice programming fundamentals, logical implementation, and problem-solving skills.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Supports numerical inputs
* ⚡ Quick and accurate calculations
* 🖥️ Simple and easy-to-use interface

## 🛠️ Technologies Used

* Python
* Tkinter
